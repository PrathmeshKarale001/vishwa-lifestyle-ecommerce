# Client Information Request Plan

To finalize the **Vishwa Lifestyle** website and replace the current AI-generated placeholders with authentic content, we need the following information and assets from the client.

## 1. Product Catalog (Critical)
We need a structured list of all products to populate the store.
*   **Product Details**:
    *   **Name**: Exact product title.
    *   **Description**: Detailed description, benefits, and usage instructions.
    *   **Price**: Selling price (and MRP if different).
    *   **SKU**: Stock Keeping Unit codes (if used).
    *   **Inventory**: Current stock levels for each item.
    *   **Categories**: How should products be grouped? (e.g., Ritual Essentials, Decor, Apparel).
    *   **Images**: High-resolution images for each product (Front, Back, Lifestyle shots).
    *   **Attributes**: Weight/Dimensions (for shipping calculations).
    *   **Ritual Significance**: (Optional) Special notes on how this product fits into Vedic rituals.

## 2. Brand Identity & Content
The current content is AI-generated. We need the client's authentic voice.
*   **Our Story**:
    *   The real story of how Vishwa Lifestyle started.
    *   Founder's background/vision.
    *   Key milestones (Timeline).
*   **Philosophy**:
    *   Specific Vedic principles the brand follows.
    *   Core values (e.g., Sustainability, Authenticity).
*   **Homepage Copy**:
    *   Main headline (Hero section).
    *   Key selling points (Why choose Vishwa?).

## 3. Legal & Policies
These are legally required for an e-commerce store in India.
*   **Terms of Service**: Legal agreement for using the website.
*   **Privacy Policy**: How customer data is handled.
*   **Return & Refund Policy**:
    *   Return window (e.g., 7 days).
    *   Conditions for return (e.g., unused, original packaging).
    *   Non-returnable items (e.g., consumables like Ghee).
*   **Shipping Policy**:
    *   Shipping partners/carriers.
    *   Estimated delivery times.
    *   Shipping charges (Free shipping threshold?).

## 4. Operational Details
*   **Payment Gateway**:
    *   CCAvenue credentials (Merchant ID, Access Code, Working Key) for Test & Live modes.
*   **Contact Information**:
    *   Customer Support Email.
    *   Phone Number (optional).
    *   Physical Address (for footer/legal).
*   **Social Media**:
    *   Links to Instagram, Facebook, YouTube, etc.

## 5. FAQs ("Excuses")
Common questions customers might ask to reduce support tickets.
*   "How do I perform Agnihotra?"
*   "Is the cow dung ethically sourced?"
*   "Do you ship internationally?"
*   "What if my copper pyramid gets tarnished?"

## 6. Visual Assets
*   **Banner Images**: High-quality wide images for the Homepage, Story page, and Shop headers.
*   **Favicon**: (Already updated, but confirm if they have a specific preference).
