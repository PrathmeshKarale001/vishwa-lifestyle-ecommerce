## 🔄 **What Changes (Technical)**

### React Version
```jsx
// Components are React/TypeScript
import { motion } from "framer-motion";

export default function Hero() {
  return <motion.div>...</motion.div>;
}
```

### Shopify Version
```liquid
<!-- Components are Liquid templates -->
{% schema %}
{
  "name": "Hero",
  "settings": [...]
}
{% endschema %}
```

**But visually, they look identical!**
